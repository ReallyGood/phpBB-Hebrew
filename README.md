phpBB3 Hebrew Translation
=========================

This repository contains the official Hebrew localization of phpBB.  
Current supported phpBB version: **3.3.15**.

## Contribute

You can report mistakes and send suggestions (in Hebrew) in the dedicated forum:  
[http://phpbb.co.il/viewforum.php?f=26](http://phpbb.co.il/viewforum.php?f=26)
